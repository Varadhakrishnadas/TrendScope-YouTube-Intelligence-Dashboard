# 📊 TrendScope – YouTube Intelligence Dashboard

> A Python-based analytics project for exploring YouTube video performance, audience engagement, sentiment, SEO-related metrics, and view forecasting using the YouTube Data API.

---

## 🚀 Project Overview

TrendScope is a YouTube analytics project that uses data from the **YouTube Data API** to explore video performance and engagement patterns.

The project combines data collection, data processing, exploratory analysis, visualization, sentiment analysis, SEO scoring, and basic machine learning-based view forecasting to provide analytical insights into YouTube content performance.

The main goal is to understand how different video and engagement metrics can be analyzed to identify patterns and support data-driven content insights.

---

## 🎯 Objectives

- Collect YouTube video data using the YouTube Data API
- Analyze video views, likes, and comments
- Explore engagement patterns across videos
- Perform basic sentiment analysis using TextBlob
- Calculate SEO-related scores
- Visualize video performance and trends
- Apply machine learning techniques for view forecasting
- Present analytical insights from the collected data

---

## ✨ Key Features

### 📈 Engagement Analysis
Analyzes important YouTube engagement metrics including:

- Views
- Likes
- Comments
- Engagement-related patterns

### 💬 Sentiment Analysis
Uses **TextBlob** to perform basic sentiment analysis on available video-related text.

### 🔎 SEO Scoring
Calculates SEO-related scores to provide an additional perspective on video optimization.

### 📊 Data Visualization
Uses **Matplotlib** to visualize video performance and identify trends in the analyzed data.

### 📉 View Forecasting
Applies machine learning techniques to explore and forecast potential video view trends.
